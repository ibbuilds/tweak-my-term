# Install and first config for Hyprland
Install `hyprland` from the distro (see tool.json), then log in from a display manager session or run `start-hyprland` from a TTY. On first start Hyprland writes an example config if none exists.

## Config
- Path: `$XDG_CONFIG_HOME/hypr/hyprland.lua` (usually `~/.config/hypr/hyprland.lua`), or `--config <file>` / `-c`.
- The generated file contains `hl.config({ autogenerated = true })`; delete that line to drop the yellow warning.
- Check the version first: `Hyprland --version`.

```lua
-- minimal skeleton to extend (0.55+)
local terminal = "kitty"
hl.config({ general = { layout = "dwindle" } })
hl.bind("SUPER + Q", hl.dsp.exec_cmd(terminal))
```

## Notes
- Lua since 0.55. On 0.54 and older the file is `hyprland.conf` (hyprlang): `general { gaps_in = 5 }` and `bind = SUPER, Q, exec, kitty`.
- Copy the maintained example rather than hand-writing everything: `example/hyprland.lua` in the Hyprland repo (it is also what the autogenerated file contains).
- Draft in the run folder and let `tmt stage` place it; never edit a live config directly.
- Split theme values into a separate file and load it with `require("myColors")` (Lua `require` works in the config).
